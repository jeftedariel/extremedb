# ExtremeDatabase

Web para explorar el catálogo de ExtremeTech y el **histórico de precios**.

[Visitar](https://extremedb.mendozac.cr/)

![demo](docs/demo.png)


Los datos y las imágenes los **recopila un scraper privado** esta web unicamente expone la información recopilada





## Nota sobre el histórico

La gráfica y las estadísticas se enriquecen conforme el tracker corre a diario y detecta
cambios (El primer run en produccion se realizó el 24jul, los datos son apartir de esta fecha)
